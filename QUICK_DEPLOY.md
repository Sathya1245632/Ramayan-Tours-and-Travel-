# 🚀 1-Minute Deployment Guide (Zero-Backend / Serverless)

Your website is now **100% frontend and serverless** — **No Database or Backend Setup Required!**

All bookings, inquiries, and customer communication connect directly to your **WhatsApp (+91 7639 661 626)** with automated reference numbers.

---

## **Step 1: Push Your Code to GitHub**

```bash
git add .
git commit -m "Deploy: Ramayan Tours and Travels"
git push origin master
```

---

## **Step 2: Deploy on Vercel (1 Click)**

1. Go to [vercel.com](https://vercel.com) and log in with GitHub.
2. Click **"Add New..."** → **"Project"**.
3. Select your repository `Ramayan-Tours-and-Travel-` and click **"Import"**.
4. *(Optional)* Under **Environment Variables**, add your Gemini API Key if you want real-time AI itinerary queries:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```
   *(Even without this, the website includes built-in instant smart itineraries and WhatsApp booking!)*
5. Click **"Deploy"**.
